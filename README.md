## 不过是一个懂得感恩的小朋友
  这时候，一些前辈踩过的坑，他们留下来的经验对我就是莫大的帮助！

  正是因为受到了前辈们传下来的经验，我觉得自己也有义务把自己踩过的坑也分享出来，把自己的知识在不破坏实验室信息安全的前提下分享出来！
  同时，我觉得，这样不厌其烦地整理，在pipeline已经被自己run到包浆后再整理，在出现报错时记录并整理，这样的看起来笨笨地、傻傻地、不智能地重复，从这些重复中，我学习到的东西，比一条一条提问，动辄十几点的回复，带给我的收获更多！

PS：为啥叫不加酵母的面团呢？
在法式烘焙中，面团有两种分类。一种是添加酵母的面团，很快就会发起来。一种是不加酵母的面团，面团会自己呼吸，然后慢慢膨大。我想成为不加酵母的面团！
